# شامنا SHAMNA

سوق عربي متعدد المتاجر يبدأ بقطنا وجرمانا. هذه نسخة تأسيسية قابلة للتطوير: تعرض منتجات توضيحية بوضوح عند غياب إعداد Supabase، وتدعم المصادقة والكتالوج ومسار الطلب وإدارة المتجر عند إعداد قاعدة البيانات وفق الترحيل المراجع.

## المتطلبات

- Node.js 22.12 أو أحدث (يفضل إصدار LTS مدعوماً).
- pnpm 11.25.0 (مثبت عبر `packageManager`).

## التشغيل المحلي

```sh
pnpm install
pnpm dev
```

من دون متغيرات Supabase تعمل الواجهة في وضع العرض فقط. جميع العناصر والأسعار فيه بيانات شكلية ولا يمكن شراءها.

للربط ببيئة تطوير Supabase بعد مراجعة المخطط:

1. انسخ `.env.example` إلى `.env.local`.
2. ضع عنوان مشروع التطوير ومفتاح الواجهة العامة (Publishable أو anon القديم) في الملف المحلي.
3. لا تستخدم مفتاح `service_role` في الواجهة ولا ترفع ملف البيئة إلى GitHub.
4. طبّق الترحيل على قاعدة تطوير فارغة وبعد مراجعة محتواه، ثم أنشئ أول مدير من قناة إدارية موثوقة.

لا تُطبّق migration على المشروع الموجود تلقائياً: يجب فحص بنيته أولاً واعتماد المخطط. التطبيق الحالي لا يتصل بأي مشروع حتى يوفّر المشغل متغيرات البيئة.

## الفحوصات والبناء

```sh
pnpm typecheck
pnpm lint
pnpm test
pnpm build
pnpm preview
```

البناء ينتج `dist/`. في Netlify استخدم أمر `pnpm build` ومجلد النشر `dist`، مع ضبط نسخة Node ومتغيرات البيئة من إعدادات الموقع. لا توجد إعادة توجيه SPA مخصصة حالياً لأن التنقل يستخدم روابط أقسام الصفحة ولا يستخدم مسارات عميل.

## المزايا الموجودة

- واجهة عربية RTL متجاوبة، ببحث وفلاتر للمنطقة والفئة والمتجر وتفاصيل المنتج.
- سلة محلية تحفظ العناصر في المتصفح. الطلب التجريبي محظور، والطلب الفعلي لا يعمل إلا مع Supabase.
- تسجيل ودخول بالبريد، ملف المستخدم، طلب تقديم متجر، مناطق التوصيل، إدارة مسودات المنتجات والطلبات، وموافقة المدير على المتاجر.
- عند تفعيل Supabase، يحتسب إجراء قاعدة البيانات الأسعار والمخزون والتوصيل من بياناتها، ويقسم السلة إلى طلبات متاجر منفصلة، ويدعم الدفع عند الاستلام فقط.
- مخطط PostgreSQL وسياسات RLS وStorage محفوظة في `supabase/migrations/` للمراجعة. لم يُطبّق الترحيل على أي قاعدة بيانات.

## النشر وما قبل الإطلاق

المستودع مرتبط بـ GitHub. لم تُفحص إعدادات Netlify أو Supabase عن بُعد في هذه الجلسة ولم يحصل نشر. لا تفعّل الموقع للعامة قبل التحقق من مخطط قاعدة البيانات وسياسات RLS بحسابات منفصلة، اختبار الطلب بين عدة متاجر، ضبط متغيرات Netlify، إعداد أول مدير بأمان، كتابة سياسات الخصوصية والإرجاع والتوصيل، والتحقق القانوني والتجاري المحلي.

راجع `docs/DECISIONS.md` و`docs/RELEASE_CHECKLIST.md` قبل أي إطلاق.
