# شامنا SHAMNA

سوق إلكتروني عربي متعدد المتاجر، مبني بـ React وTypeScript وVite، باتجاه RTL وتصميم متجاوب. يبدأ التركيز بقطنا وجرمانا. عند غياب إعداد Supabase يعرض الموقع منتجات توضيحية معلّمة بوضوح، ولا يسمح بطلبها.

## التشغيل

المتطلبات: Node.js 22.12 أو أحدث، وpnpm 11.25.0.

```sh
pnpm install
pnpm dev
```

للاتصال بـSupabase محليًا، انسخ `.env.example` إلى `.env.local` وأدخل رابط المشروع ومفتاح الواجهة العامة فقط. ملف `.env.local` مستثنى من Git. لا تضع مفتاح `service_role` أو أي مفتاح إداري في الواجهة.

```text
VITE_SUPABASE_URL=https://<project-ref>.supabase.co
VITE_SUPABASE_PUBLISHABLE_KEY=<publishable-key>
```

تدفق استعادة كلمة المرور يعيد المستخدم إلى عنوان الموقع الحالي بعد فتح رسالة الاستعادة. اسمح بعنوان التطوير المستخدم في **Supabase Dashboard → Authentication → URL Configuration → Redirect URLs**، مثل `http://localhost:5173/**` أو `http://localhost:5174/**` عند استخدام ذلك المنفذ. أضف عنوان الموقع المنشور إلى القائمة قبل تفعيله. لا يرسل التطبيق رسالة استعادة تلقائيًا مرة أخرى عند حدوث حدّ للبريد.

## ما يعمل في النسخة الحالية

- واجهة عربية RTL، بحث، تصفية حسب الفئة والمنطقة، صفحات مستقلة للمنتجات والمتاجر بروابط قابلة للمشاركة، وسلة محلية.
- تسجيل حساب ودخول وخروج واستعادة كلمة المرور بالبريد، وصفحة حساب للملف الشخصي والطلبات وإعدادات المتجر، وطلب إنشاء متجر، وإدارة المناطق والفئات والمتاجر والمنتجات (بما فيها تعديل بيانات المنتج وصورته) والطلبات وسجل تدقيق مختصر حسب دور قاعدة البيانات. تعرض لوحة الإدارة مؤشرات دقيقة للمتاجر والمنتجات والطلبات.
- المحفوظات تبقى على الجهاز الحالي فقط، وعناوين التوصيل تُحفظ في حساب الزبون ويمكن إعادة استخدامها.
- يستطيع الزبون فتح تفاصيل كل طلب ورؤية تقسيمه حسب المتجر، والمنتجات ورسوم التوصيل وسجل تحديثات الحالة.
- نوافذ الدخول والحساب والمنتجات والسلة والطلب تدعم لوحة المفاتيح: نقل التركيز داخل النافذة وإعادته لمكانه عند الإغلاق.
- عند ربط Supabase: تحميل الكتالوج من قاعدة البيانات، رفع صور المنتجات إلى Storage، عرض رسوم التوصيل لكل متجر قبل تأكيد السلة، وإتمام الطلب بالدفع عند الاستلام مع إعادة التحقق من السعر والمخزون والتوصيل داخل قاعدة البيانات.
- أخطاء قاعدة البيانات تتحول إلى رسائل عربية آمنة؛ لا تعرض الواجهة تفاصيل SQL أو سياسات الوصول الخام.
- لوحة الحساب تعرض وظائف الزبون والبائع والإدارة بحسب الأدوار الممنوحة من قاعدة البيانات. السياسات الفعلية تعتمد على RLS وإجراءات قاعدة البيانات.

## قاعدة Supabase الحالية

فُحص مخطط مشروع Supabase وسياسات RLS بتاريخ 2026-10-24. قاعدة البيانات تحتوي الجداول الأساسية للملفات الشخصية والأدوار والمدن والفئات والمتاجر والمنتجات والعناوين والطلبات وسجل التدقيق، مع تفعيل RLS. أعمدة المخزون وحالات المتجر تطابق ترحيل الأساس في `supabase/migrations/202610220001_initial_marketplace.sql`.

طُبّق ترحيل أمني محدود لإلغاء التنفيذ المباشر من `anon` و`authenticated` لدالتين تعملان فقط كمشغّلات قاعدة بيانات، ثم ترحيل `20261024055219_add_foreign_key_indexes.sql` لإضافة فهارس المفاتيح الخارجية السبعة التي أوصى بها Advisor. سجل الترحيل الأساسي ما زال غير ممثل فيه لأن المخطط الأصلي أُنشئ من محرر SQL. لا تشغّل ترحيل الأساس على قاعدة المشروع الحالية، لأنه يحتوي أوامر إنشاء جداول وأنواع موجودة بالفعل. استخدم `supabase migration repair` لمزامنة سجل الترحيلات قبل أي نشر migrations مستقبلي.

حماية كلمات المرور المسرّبة غير مفعّلة في إعدادات Auth، كما تبقى ملاحظات Advisor عن دوال `SECURITY DEFINER` وسياسات RLS المتعددة. راجع `docs/SUPABASE_STATE.md` قبل تعديل هذه الإعدادات أو الصلاحيات.

توجد نسخة محلية أقدم وغير مطبقة من ترحيل المرحلة الثانية في `docs/archive/local-stage2/`؛ لا تنقلها إلى مجلد migrations. تفاصيل الفحص والتنبيهات المتبقية في `docs/SUPABASE_STATE.md`.

لم نقرأ أي ملف `.env`. أُنشئ `.env.local` محليًا باستخدام رابط المشروع ومفتاح الواجهة العامة، وهو مستثنى من Git؛ لا يحتوي مفتاحًا إداريًا. لم نغيّر إعدادات البريد أو كلمات المرور أو الاستضافة.

## الفحوص

```sh
pnpm typecheck
pnpm lint
pnpm test
pnpm build
```

النشر إلى Netlify غير مفحوص في هذه المرحلة. إعداد البناء المتوقع هو `pnpm build` ومجلد النشر `dist` كما في `netlify.toml`. لا تنشر قبل إضافة متغيرات البيئة المطلوبة إلى إعدادات الاستضافة ومراجعة قائمة الإطلاق.

راجع `docs/DECISIONS.md` و`docs/RELEASE_CHECKLIST.md` و`docs/archive/local-stage2/` قبل متابعة النشر أو تغيير مخطط قاعدة البيانات.
