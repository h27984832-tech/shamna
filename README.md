# شامنا SHAMNA

واجهة أولية عربية RTL لسوق محلي متعدد البائعين. المنتجات الظاهرة في هذه النسخة أمثلة تجريبية للتصميم وليست عروضاً تجارية حقيقية. لا تتصل هذه النسخة بقاعدة بيانات أو بوابة دفع.

## المتطلبات

- Node.js 20.19+ أو 22.12+
- مدير حزم مثل npm أو pnpm

## التشغيل

```sh
pnpm install
pnpm dev
```

## البناء

```sh
pnpm build
pnpm preview
```

يُنتج البناء ملفات الموقع في `dist/`، وهو مجلد النشر المعتاد لمواقع Vite الثابتة.

## الحالة الحالية

- React + TypeScript + Vite.
- واجهة تجريبية متجاوبة باللغة العربية واتجاه RTL.
- البحث والتصفية حسب الفئة والمنطقة، وإضافة العناصر إلى سلة محلية تجريبية.
- لم يُربط Supabase أو المصادقة أو الدفع. لا توجد مفاتيح أو ملفات بيئة في المستودع.

## قرارات تقنية

- البدء بواجهة Vite خفيفة دون مكتبات تصميم إضافية، لتقليل حجم التنزيل ودعم الاتصال المحدود.
- إبقاء عناصر الكتالوج تجريبية وواضحة حتى اعتماد بيانات البائعين الفعلية.
- يؤجل تصميم قاعدة البيانات وسياسات RLS إلى مرحلة مستقلة بعد مراجعة المخطط.
