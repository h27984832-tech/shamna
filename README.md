# شامنا SHAMNA

واجهة سوق سوري متعدد المتاجر، مبنية باستخدام React وTypeScript وVite، مع واجهة عربية RTL وربط اختياري بـSupabase.

## الوضع الحالي

- الصفحة الرئيسية والبحث والتصفية حسب الفئة والمنطقة تعمل ببيانات العرض عند غياب إعداد Supabase، أو بكتالوج قاعدة البيانات عند ضبط الإعدادات.
- يمكن حفظ المنتجات وإضافتها للسلة التجريبية، ومراجعة محتوى السلة وإزالة المنتجات منها. لا تحفظ البيانات بين الجلسات ولا ترسل السلة طلبًا.
- نافذة الحساب تنفذ إنشاء الحساب وتسجيل الدخول والخروج عبر Supabase Auth عند الإعداد، وتوضح تأكيد البريد وحدود الإرسال دون إعادة إرسال تلقائية.
- يمكن فتح تفاصيل المنتج والمتجر واستعراض منتجات المتجر؛ تظل الإضافة إلى السلة تجريبية ولا تنشئ طلبًا.
- يستطيع المستخدم المسجل تقديم طلب إنشاء متجر ومتابعة حالته؛ الطلب يخضع لمراجعة الإدارة ولا يمنح دور البائع تلقائيًا.
- عند ضبط Supabase، لا تستبدل أخطاء الشبكة أو الكتالوج الفارغ ببيانات أمثلة. شريط الحالة يوضح أن الطلب والدفع غير مفعّلين.
- عند عدم ضبط Supabase، تظهر المنتجات والمتاجر والأسعار كأمثلة غير حقيقية بوضوح.
- Migration قاعدة البيانات محلية للمراجعة فقط؛ لم تطبق على أي مشروع Supabase.

## التشغيل المحلي

يتطلب Node.js 22.12 أو أحدث وpnpm 11.25.

```sh
pnpm install
pnpm dev
```

## إعداد Supabase للتطوير

1. انسخ `.env.example` إلى `.env.local` على جهاز التطوير.
2. املأ `VITE_SUPABASE_URL` و`VITE_SUPABASE_PUBLISHABLE_KEY` من إعدادات مشروع التطوير. المفتاح القابل للنشر مخصص للواجهة العامة ويجب أن تحمي البيانات سياسات RLS؛ لا تضع مفتاح `service_role` أو أي سر في متغير يبدأ بـ`VITE_`.
3. أعد تشغيل خادم Vite بعد تغيير متغيرات البيئة.
4. راجع `supabase/migrations/202610230001_stage2_auth_catalog.sql` وقارنها بمخطط المشروع المستهدف قبل تطبيقها يدويًا. لا تشغّلها على الإنتاج قبل مراجعة المخطط والحصول على موافقة صريحة.
5. إعدادات تأكيد البريد وروابط إعادة التوجيه وحدود البريد تبقى ضمن إعدادات Supabase؛ لم يجر تعديلها من التطبيق.

المتغيرات المطلوبة أسماؤها موجودة في `.env.example` بقيم فارغة، ولا يتضمن المستودع ملف بيئة محليًا.

لفحص TypeScript وبناء نسخة الإنتاج:

```sh
pnpm typecheck
pnpm build
```

## ما لم يكتمل بعد

- تطبيق ومراجعة migration على بيئة تطوير Supabase منفصلة أو بعد فحص مخطط المشروع الحالي.
- اختبار تسجيل الحساب وتأكيد البريد وتسجيل الدخول على بيئة تطوير، خصوصًا حدود البريد وإعدادات إعادة التوجيه.
- لوحة إدارة المنتجات للبائع والملف الشخصي والطلبات غير مكتملة.
- السلة ما زالت للعرض فقط؛ لا تنشئ طلبًا ولا تدعم الدفع أو العناوين أو المخزون الحي.
- لم يجر رفع أو commit أو نشر أي ملفات.
