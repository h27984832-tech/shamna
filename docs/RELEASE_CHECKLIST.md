# قائمة ما قبل الإطلاق

## الإعداد والتحقق

- [ ] تثبيت الحزم وإنشاء/مراجعة ملف القفل الملتزم بالمستودع.
- [ ] نجاح `pnpm typecheck`, `pnpm lint`, `pnpm test`, و`pnpm build`.
- [ ] معاينة الهاتف وسطح المكتب وRTL ولوحة المفاتيح وقارئ الشاشة.
- [ ] فحص أداء الصفحة على اتصال بطيء؛ لا توجد صور منتجات فعلية مرفقة حالياً.

## Supabase

- [ ] فحص قاعدة المشروع الموجودة وسياساتها قبل أي ترحيل.
- [ ] مراجعة migration في بيئة تطوير منفصلة وأخذ نسخة احتياطية قبل التطبيق.
- [ ] اختبار RLS بحساب زبون وبائعين اثنين ومدير: لا يرى البائع بيانات بائع آخر ولا طلبات زبون آخر.
- [ ] اختبار الطلب المتعدد المتاجر، المخزون المتزامن، منطقة غير مدعومة، الإلغاء، وانقطاع الشبكة.
- [ ] إسناد دور المدير الأول بأمان ومراجعة صلاحياته.
- [ ] تحديد سياسة كلمات المرور وتأكيد البريد والاستعادة وحدود المحاولات.

## Netlify والإطلاق

- [ ] تأكيد إعداد المستودع والفرع وأمر البناء ومجلد `dist` في الموقع الموجود.
- [ ] ضبط `VITE_SUPABASE_URL` و`VITE_SUPABASE_PUBLISHABLE_KEY` في إعدادات بيئة Netlify فقط.
- [ ] التأكد أن أي مفتاح سري أو ملف بيئة محلي غير موجود في Git أو build output.
- [ ] نشر معاينة غير إنتاجية وفحص سجل البناء ومسار الطلب.
- [ ] كتابة ومراجعة الخصوصية والشروط والإلغاء والاسترجاع والتوصيل والتحقق القانوني المحلي.
- [ ] تجهيز النسخ الاحتياطي والاستعادة ومراقبة الأعطال والدعم قبل الإطلاق المحدود.

## عناصر لم تُنجز/لم تُتحقق

- لم يُفتح حساب Netlify أو مشروع Supabase ولم تُقرأ إعداداتهما في هذه الجلسة.
- لم يُطبّق SQL على أي قاعدة بيانات، ولم يُنفّذ نشر.
- لم تُثبت الحزم أو تُنفّذ الفحوصات حتى الآن بسبب خطأ صلاحية قراءة مسار المستودع من pnpm؛ راجع نتيجة التحقق في تقرير التنفيذ.
