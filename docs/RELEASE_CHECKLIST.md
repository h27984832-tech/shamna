# قائمة ما قبل الإطلاق

## الإعداد والتحقق

- [x] تثبيت الحزم وإنشاء/مراجعة ملف القفل الملتزم بالمستودع.
- [x] نجاح `pnpm typecheck`, `pnpm lint`, `pnpm test`, و`pnpm build` محليًا.
- [x] تنفيذ حصر التركيز داخل النوافذ، الإغلاق بـEscape، وإعادة التركيز لعنصر الفتح.
- [x] تقسيم نوافذ الحساب والدخول والطلب لتحميلها عند الحاجة وتقليل حزمة الصفحة الأولى.
- [ ] معاينة يدوية للهاتف وسطح المكتب وRTL ولوحة المفاتيح وقارئ الشاشة.
- [ ] فحص أداء الصفحة على اتصال بطيء؛ لا توجد صور منتجات فعلية مرفقة حالياً.

## Supabase

- [x] فحص قاعدة المشروع الموجودة وسياساتها قبل أي ترحيل.
- [x] مراجعة مصدر migration محليًا: RLS مفعّل على الجداول العامة الـ13 ولا يوجد منح `anon` لجداول العناوين والطلبات والتدقيق. هذا فحص ساكن ولا يستبدل اختبارًا على قاعدة اختبارية.
- [x] إضافة فحوص ساكنة تؤكد قيود ملكية الملف الشخصي والعناوين والمنتجات وعناصر الطلبات، ومنع منح دور مباشرة، وحماية دوال `SECURITY DEFINER`.
- [ ] مراجعة migration في بيئة تطوير منفصلة وأخذ نسخة احتياطية قبل التطبيق.
- [ ] اختبار RLS بحساب زبون وبائعين اثنين ومدير: لا يرى البائع بيانات بائع آخر ولا طلبات زبون آخر.
- [x] حساب تقدير رسوم التوصيل لكل متجر في السلة، ومنع التأكيد عند غياب منطقة تغطية؛ يلزم اختبار التدفق على قاعدة اختبارية.
- [x] عرض تفاصيل الطلب وسجل حالة كل متجر للزبون اعتمادًا على علاقات قاعدة البيانات؛ يلزم التحقق بحساب زبون وطلب فعلي في بيئة اختبار.
- [ ] اختبار الطلب المتعدد المتاجر، المخزون المتزامن، منطقة غير مدعومة، الإلغاء، وانقطاع الشبكة.
- [x] إسناد دور المدير الأول إلى حساب مالك المشروع والتحقق من الأدوار دون كشف بيانات الحساب.
- [x] تنفيذ واجهة طلب رابط استعادة كلمة المرور وتعيين كلمة جديدة؛ لا توجد إعادة إرسال تلقائية.
- [ ] تحديد سياسة كلمات المرور وتأكيد البريد والاستعادة وحدود المحاولات، والتحقق من Redirect URLs وقوالب البريد وإرسال الاستعادة في بيئة اختبار.

## Netlify والإطلاق

- [ ] تأكيد إعداد المستودع والفرع وأمر البناء ومجلد `dist` في الموقع الموجود.
- [ ] ضبط `VITE_SUPABASE_URL` و`VITE_SUPABASE_PUBLISHABLE_KEY` في إعدادات بيئة Netlify فقط.
- [ ] التأكد أن أي مفتاح سري أو ملف بيئة محلي غير موجود في Git أو build output.
- [ ] نشر معاينة غير إنتاجية وفحص سجل البناء ومسار الطلب.
- [ ] كتابة ومراجعة الخصوصية والشروط والإلغاء والاسترجاع والتوصيل والتحقق القانوني المحلي.
- [ ] تجهيز النسخ الاحتياطي والاستعادة ومراقبة الأعطال والدعم قبل الإطلاق المحدود.

## عناصر لم تُنجز/لم تُتحقق

- لم يتم التحقق من إعدادات Netlify أو تنفيذ نشر.
- طُبق ترحيل أمني محدود للدالتين المشغلتين فقط؛ راجع `SUPABASE_STATE.md`.
- لم تُجر اختبارات RLS بحسابات زبون وبائع ومدير منفصلة.
- لا توجد حاليًا أدوات Supabase CLI أو Docker أو psql في بيئة التطوير هذه، لذلك تعذر تشغيل قاعدة اختبار محلية واختبار البريد وRLS تكامليًا.
- أُنشئ `.env.local` محليًا بقيم الواجهة العامة فقط وهو مستثنى من Git. إعداد Netlify لم يُفحص، لذلك لا يُعرف إن كانت بيئة الموقع المنشور مربوطة بـSupabase.
